# Insights & Demand reference rebuild — 8 October 2026

The new admin navigation section consumes `analytics.insights`; the GPT reference is `insights-demand-dark-concept.png`. The website renders actual first-party event/account/listing aggregates, not the reference's illustrative numbers. Periods are 7/30/90 UTC calendar days including today. Unique visitors are distinct recorded browser sessions, not identified people. Daily uniqueness is independently counted; adding daily counts is not the period unique count.

Cart rows contain actual listing photos, current marketing-only labels, add actions and units. Existing historical add-to-cart and no-result records are included. Successful text searches, category tags and successfully connected Gaffer calls are now instrumented. Reconnection of an existing call is excluded. There is no historic backfill for previously unrecorded metrics. Voice call counts are not rental chat counts. Sitewide checkout/interest counts are labelled separately rather than presented as attributed Gaffer conversions.

Memberships use the shared current entitlement predicate, including blocking, expiry, pending perks and explicit complementary/admin grants. New figures count currently active memberships starting within the period; scheduled cancellation is current account state, not an invented cancellation-history figure. Account/private identifiers are not returned. Top equipment is capped at 25, search rankings at 20, page rankings at eight. CSV quotes fields and neutralises spreadsheet formulas. Public analytics are observational and can be inflated by client traffic; they are not financial truth.
