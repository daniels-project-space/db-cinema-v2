# Website requirement audit — 1 October 2026

Latest request: restore the visible basket/checkout membership upsell and one-click addition, audit earlier website requests, and place Film Fund below the homepage gear catalogue. Current source and real callers were inspected; earlier checklist ticks alone were not accepted as proof.

## Gaps corrected in this release

- Basket page and slide-out basket did not render the membership offer at all. Both now render the same widget and request authoritative pricing.
- Checkout recommendations waited for completed contact/address/time fields. Pickup quotes now load from actual cart items before contact entry. The add button also works while recommendations are loading; recommendations update to the best-priced plan for the basket when available.
- Membership choice lived only in checkout state. Cart provider now owns the selection across drawer, basket and checkout; only tier/intro are persisted. Reload and account changes require fresh terms consent. Emptying the kit clears the selection. Existing members cannot accidentally carry a second membership selection.
- Basket totals used a local formula that omitted the selected subscription fee, member/repeat security exemption and weekend nonstacking rules. Basket and drawer now use checkout's server calculation, including available credit, separate security payment, full uncharged hold and selected membership fee. Delivery is priced at checkout for the chosen address.
- The recommendation endpoint used the raw membership flag, while pricing used effective entitlement. Expired paid subscriptions now receive recommendations, and current subscribers do not receive duplicate subscription offers.
- Benefits popup was nested inside a clipping/transformed card. It now renders into the document body, fits mobile, closes on Escape, contains keyboard focus and restores focus/scroll on close.
- Asynchronous account loading left contact fields blank. Saved contact details now fill initially empty fields without overwriting entered text. Payment still requires account resolution, complete contact/fulfilment details, current quote and all agreements.
- Checkout header is shorter so the membership CTA appears earlier on phones. Its security indicator no longer claims a payment is processing before payment begins.
- Homepage Fund invitation now follows featured gear and catalogue categories, before How it works.
